# つたえてドン！

スマホをおでこに当てて、周りの人のジェスチャーでお題を当てるパーティーゲームです。

**遊ぶ：** https://koooosuke-oki.github.io/odeko-don/

## あそびかた

1. カテゴリを選んで、スマホを横向きにしておでこに当てます。
2. 周りの人がジェスチャーや説明でお題を伝えます（お題の言葉そのものは言っちゃダメ）。
3. わかったら下に傾けて正解、わからなければ上に傾けてパス。
4. 時間切れまでにたくさん当てよう！

## ファイル

- `index.html` … 画面
- `style.css` … 見た目
- `app.js` … ゲームの動き・傾き検出
- `words.js` … お題（カテゴリの追加はここ）
